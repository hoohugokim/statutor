# Plan: v0.3.1 truthful trust floor

## Objective

Restore agreement between Statutor's public claims and its enforced behavior
before expanding its scope. This is a patch milestone: no new harness and no
server mode. A true pre-receive/ref-range floor remains later work.

## Confirmed failures

1. **The advertised pre-receive hook is inert.** A bare repository has no
   worktree or index for `git diff --cached`; its documented
   `git rev-parse --show-toplevel` fails, and both kernels discard the git
   error and return clean. Reproduced against a fresh bare repository.
2. **The published crate contains local build output.** Eighty-three tracked
   files under `crates/statutor/target/` occupy about 13 MB. The retained
   5,486,075-byte crate checksum equals the live crates.io 0.1.0 checksum and
   contains the Mach-O binary, rlibs, fingerprints, and local absolute paths.
3. **Governed records can leave the ledger.** Exact renames of every governed
   basename to an ungoverned name pass; direct AGENTS and TASKS deletion pass.
   apply_patch Move has the same non-frozen gap.
4. **Rendered diffs are not a safe append-only primitive.** NUL content or an
   unstaged `.gitattributes` `-diff` rule turns a wholesale DECISIONS rewrite
   into "Binary files differ," so the minus-line scan sees zero deletions.
5. **The policy source is not a trust root.** Staged validation reads the
   worktree `.statutor.yaml`; an unstaged `governed: []` disables checks on a
   different staged ledger mutation. A committed empty policy disables later
   checks entirely. CLAUDE.md's AGENTS import is also ungoverned.
6. **State claims exceed state enforcement.** TASKS can be rewritten, deleted,
   or shell-mutated; doctor does not validate unique/stable task IDs despite
   the README saying it does.
7. **Shared parity can certify shared bugs.** A physical 40-line trailing-
   newline file is counted as 41 by both kernels. Quoted YAML caps diverge,
   explicit-CWD relative paths resolve against the process, and sized Edit is
   unchecked.
8. **Drift reporting has failure paths.** An impossible verification date can
   crash doctor and make Stop hide all findings; a generic AGENTS-only repo is
   mistaken for a Statutor ledger by a user-scope plugin.

## Task order

- **Trust contract fixed by D-0015:** HEAD is the current authority, the index policy
  is the candidate next authority, trust roots sit outside self-configuration,
  and an exact-tree local receipt is the supported explicit escape.
- **Package cleanup complete (2026-08-31):** generated Cargo output is
  untracked; 0.1.1 crate/npm allowlists and license files are exact; CI opens
  both real archives; conformance returns the isolated binary it built.
- **Lifecycle floor repaired (2026-08-31):** Python and Rust use raw HEAD/index
  blobs, protect record paths and frozen arrivals, fail closed on Git errors,
  and carry expected verdicts—not parity alone. Hook mode remains fail-open.
- **Cross-layer floor complete (2026-08-31):** HEAD and index policies both judge the
  transaction; protected roots require exact-tree receipts; the dependency-
  free parser, physical line counts, quoted caps, explicit-CWD paths, and sized
  Edit checks agree across Python and Rust.
- **T-0027 next:** define `state` before enforcing it. At minimum, full TASKS blobs
  have valid unique IDs and existing IDs cannot silently change or disappear;
  any pruning/archive path must preserve identity history.
- **T-0028/T-0029:** make drift detection and every public claim exact. Remove
  pre-receive/static claims rather than leaving aspirational wording.
- **T-0030 last:** one release gate owns tests, built-artifact installation,
  tag/version parity across package metadata, and publication order.

## Required regression matrix

- delete and rename-out for constitution, bounded state, append-only log, and
  TASKS; rename into/out of archive; direct new archive add;
- text rewrite, NUL rewrite, hostile attributes/config, missing index, bare
  repository, git subprocess error, and unusual path quoting;
- committed, staged, and unstaged policy combinations, including weakening;
- exact cap with and without trailing newline; numeric and quoted YAML caps;
- relative/absolute file paths with process cwd different from project cwd;
- invalid and future HANDOFF dates; generic AGENTS-only directory; nested cwd;
- package contents for wheel, sdist, npm tarball, and crate, including LICENSE
  and absence of caches, binaries, absolute build paths, and `target/`.

## Release gate

- A normal clean checkout builds the Rust binary outside the source tree and
  runs semantic assertions plus Python/Rust differential conformance.
- `git ls-files crates/statutor/target` is empty.
- Package inspections run in CI before any immutable registry upload.
- PyPI publication waits for the test job and verifies pyproject/plugin tag
  parity; npm/crate patch publication is human-confirmed after dry runs.
- `statutor-doctor .` and `statutor staged .` are clean.
- README and adapter examples contain no placeholder URL, stale matcher, old
  vulnerable revision, or staged-as-pre-receive claim.

## Non-goals

- No history rewrite for the already-public build artifacts unless a separate
  privacy review finds secrets; ordinary removal plus a clean patch is enough.
- No true server hook in this patch. Pre-receive must inspect pushed ref ranges
  and tree blobs, which requires a new decision and conformance model.
- No global-home mutation; that belongs to the next milestone and always
  requires a separate explicit apply operation.
