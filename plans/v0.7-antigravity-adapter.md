# v0.7 Google Antigravity adapter

Task: T-0044. Decided: first-class Antigravity adapter and kernel compatibility (D-0025); zero third-party dependencies.

## Goal

Provide native, seamless integration with Google Antigravity (AGY / Gemini harness)
alongside Claude Code, Codex, and OpenCode, with zero background daemons and
100% fail-open hook safety.

## Scope

1. **Tool and Argument Normalization**:
   Kernel `_norm` and `validate` handle Antigravity tool names (`run_command` -> `bash`,
   `write_to_file` -> `write`, `replace_file_content` -> `edit`) and PascalCase argument
   keys (`TargetFile`, `CodeContent`, `CommandLine`, etc.).
2. **Pre-mutation & Stop Hooks**:
   `statutor hook` auto-detects Antigravity's PreToolUse and Stop schemas via stdin payload
   inspection, outputting Antigravity protojson (`{"decision": "allow"|"deny"}`). Stop hook
   runs `statutor-doctor` with drift continuation bounded to 1 turn.
3. **Plugin Bundle**:
   `adapters/antigravity/` ships as a complete plugin containing `plugin.json`, `hooks.json`,
   `rules/AGENTS.md` (projecting the 4 planes), and 5 skills (`statutor`, `statutor-init`,
   `statutor-doctor`, `handoff`, `decide`).
4. **Worker Provenance**:
   Register `antigravity` and `gemini` in `statutor_worker.HARNESSES` and `CAPABILITIES`.
